# NumQuest

A gamified study course for **CENSCP33Z · Numerical Solutions to CE Problems**. Five worlds — Roots, Matrix Fortress (with Determinants & Adjoint Inverses), Data Valley, Integration Peaks, and the optional Differential Frontier (ODE IVP/BVP Honours) — featuring interactive labs, visual worked solutions, checkpoints, bosses, and a Course Certificate. Open `index.html`; progress is saved locally in your browser.
